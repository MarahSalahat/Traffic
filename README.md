# 🚦 TraffiSense

**TraffiSense** is a smart web application that utilizes frontend technologies, **Node.js**, and **AI models** to monitor and predict traffic flow. Designed to provide real-time insights and encourage collaboration, the app features interactive pages for weather-based congestion forecasting, analytical charts, and a community forum.

## 🌟 Key Features

- 🌍 **Weather-Based Congestion Prediction**  
  Provides congestion level predictions based on user location and current weather conditions.

- 📊 **Tableau-Integrated Congestion Chart**  
  Displays critical congestion data through an embedded Tableau chart for rich visual analysis.

- 📉 **Insights & Analysis Page**  
  Features additional visualizations and insights to help users understand traffic patterns and correlations.

- 💬 **Community Forum**  
  Enables users to discuss traffic management strategies, share ideas, and collaborate.

## 🧰 Tech Stack

- **Frontend**: HTML, CSS/Sass, JavaScript
- **Backend**: Node.js, Express.js
- **AI/ML**: Congestion prediction model (trained on weather and traffic data)
- **Data Visualization**: Tableau
- **Forum**: Custom discussion module
